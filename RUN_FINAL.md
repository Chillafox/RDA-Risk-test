## 6. Troubleshooting

- **Missing JSON**: run each Task 1–5 JSON export first; check the `Excel_Template_Output` folder.
- **`dotnet` not recognized**: install .NET 10 SDK, restart the terminal and re-run.
- **NuGet / network**: allow the package restore for ClosedXML 0.105.1 or use the organizational NuGet source as allowed.
- **Missing C# file**: put `DeskRiskWorkstation_Final.cs` in `Excel_Template_Design`, not in a Python Cell.
- **Output Excel is already open**: close it before rerunning C# to avoid file locks.
- **QA failures**: do not bypass the check. Identify the mismatching task snapshot and rerun that task's export.
- **Excel date dropdown missing**: open in desktop Excel; data validation is generated by ClosedXML. You can still type a valid ISO date (`2024-11-20`) from the 2024 range.
